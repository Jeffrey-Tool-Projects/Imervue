## U-20261102-01 · 2026-11-02 · Require Python 3.11; stop supporting 3.10 · #migration #deps #ci

- **Why**: every package in the workspace moves its floor to Python 3.11 together. Security releases such as Pillow 13.0.0 need 3.11, and supporting 3.10 kept older, vulnerable versions in the locks.
- **What**: `requires-python` is `>=3.11` and the 3.10 classifier is gone; the CI matrices start at 3.11; the docs that gave 3.10 as the floor now give 3.11.
- **Locks**:
  - `uv.lock`: the 3.10-only branches are gone; removed: `exceptiongroup`, `tomli`, `typing-extensions`; one version left instead of a 3.10 one beside it: `numpy`, `stevedore`.
- **Also**: `uv.lock` also catches up with `pyproject.toml`: it now locks PySide6 6.12.0, which `pyproject.toml` already pinned, and the project's current version. The README badges and requirement lines say 3.11.
- **Lint**: ruff's py311 target turns on rules that 3.10 kept off. `datetime.UTC` replaces `timezone.utc` (UP017), and `tests/test_release_workflow.py` imports `tomllib` directly instead of guarding it (UP036). UP042 (`StrEnum`) is ignored, because `StrEnum` changes what `str()` returns.
- **Open items**: none.

## U-20261104-01 · 2026-11-04 · Deep Zoom gives the image the whole window · #feature #ui

- **Why**: in Deep Zoom the picture was small. The Folders and Image Info docks and the two-row filter bar kept their room around it, the fit never enlarged a picture past 100 %, and the minimap reserved a band of up to 152 px at the bottom even with the whole image in view.
- **What**: entering Deep Zoom folds the docked Folders and Image Info panels and the filter row into icon buttons on the file-name row (`gui/deep_zoom_chrome.py`); each button brings its panel back while Deep Zoom stays open, and leaving restores the layout from before. Floating docks are left alone; theater mode holds the panels while it is on. A dock layout saved in Deep Zoom (on close, into a workspace) is the unfolded one, and a layout applied or reset in Deep Zoom is folded again. Fit to window now fills the canvas, enlarging a small picture up to the 5000 % zoom ceiling. The minimap shows only while the image overflows the canvas and reserves no band; only the optional filmstrip still reserves one.
- **Files**: `Imervue/gui/deep_zoom_chrome.py` (new), `gui/main_window_layout.py`, `gui/main_window_docks.py`, `gui/main_window_views.py`, `gui/tool_icons.py`, `gpu_image_view/fit_view.py`, `gpu_image_view/deep_zoom_renderer.py`, `gpu_image_view/view_resources.py`, `gpu_image_view/deep_zoom_loading.py`, five `multi_language` dictionaries, ten READMEs, ten `docs/<lang>/index.rst`.
- **Tests**: `tests/test_deep_zoom_chrome.py` (new); `test_fit_view.py` and `test_deep_zoom_renderer.py` now pin the fill fit and the minimap rule; `test_main_window_docks.py`, `test_main_window_layout.py` (a real window folds and restores on a deep-zoom load), `test_gpu_image_view_contracts.py`.
- **Open items**: none.

## U-20261104-02 · 2026-11-04 · Keep the folder tree after Deep Zoom or theater mode · #fix #ui

- **Symptom**: the folder tree was gone after a restart. The saved `browse_dock_state` held the Folders and Image Info docks hidden: a session started from a half-finished tree of U-20261104-01 folded them in Deep Zoom and saved that on close.
- **What**: saving a dock layout now also counts the docks theater mode hid as shown (`MainWindowViewsMixin._theater_docks_shown`), next to the Deep Zoom fold (`DeepZoomChrome.uncollapsed`), so closing in either mode saves the layout the user left. Theater mode records each widget with `isHidden()` instead of `isVisible()`; entered from another main tab, it saw the Imervue tab's docks as not visible and hid them for good on exit.
- **Recovery**: a layout already saved with the tree hidden comes back through Thumbnail Size > Panels > Folders, or Reset Panel Layout.
- **Tests**: `tests/test_main_window_docks.py` (saving in theater mode, theater over Deep Zoom, theater entered from Modify; the last two fail on the old code), `tests/test_main_window_layout.py` (a real window closed in Deep Zoom saves the unfolded docks).
